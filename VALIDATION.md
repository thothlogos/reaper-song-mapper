# Validation

Verified on November 10, 2026, using REAPER **7.82/macOS-arm64**, ReaImGui **0.10.0.5**, and Lua **5.4**.

- **25 unit tests:** musical boundaries, mixed meters, count-in, fractional BPM, section identities and numbering, reordering/duplication, validation, safe serialization, and draft/revision synchronization.
- **14 integration scenarios in actual REAPER:** map creation and replacement, preserving unrelated regions and markers, colors, Undo/Redo with the correct section data, stale revision refusal, manual timeline edits, media-item protection, injected playback states, recovery from failed region creation, preventing Redo of partial failures, mixed meters, save/reopen, and project-tab binding.
- **Live setup:** installed ReaImGui through ReaPack, restarted REAPER, registered the Song Mapper action, and added its button to the main toolbar.
- **Visual check:** the example renders with the expected section labels, ranges, colors, tempo values, and 37.82-second estimate. The user confirmed that clicking Add section adds a row. Automated clicks into the ReaImGui window were unreliable, so full mouse/keyboard interaction coverage is not claimed.

The integration suite uses disposable project tabs and returns to the original project. It does not touch band recordings. Playback/recording guard tests inject transport-state return values; metronome audio was not auditioned.

To reproduce, follow the Development and verification section in `README.md`. Local logs are `tests/integration-results.txt` and `tests/probe-results.txt` (excluded from version control). `examples/Sample Song.rpp` is a real REAPER project generated by the integration suite.

Implementation findings:

- REAPER project extension data does not follow Undo/Redo, but master-track `P_EXT` values do. Immutable saved revisions plus an undoable active reference preserve the correct editor state.
- A no-op recovery checkpoint is optimized away by REAPER. Failed operations therefore change a private recovery stamp after rollback, creating a real checkpoint that clears ordinary Redo of the partial failure.

## macOS installer (November 11, 2026)

Eight isolated macOS tests cover a no-write dry run, repeat installation, dependency preservation, backups, conflicting binaries, concurrent locks, unmanaged folders, symlink destinations, failed download checksums, and rollback after replacement fails. Fixtures use a disposable fake app bundle and resource directory; they never launch REAPER. The existing 25 Lua tests and syntax checks still pass. The real development installation also passes preflight with `--dry-run`.

Official ReaImGui 0.10.0.5 binaries and the Lua shim were downloaded and their SHA-256 digests pinned. Inspection of the Intel binary's Mach-O load commands reports minimum macOS 10.9. End-to-end installation on a fresh Mac, registration by the new installer, Rosetta execution, and macOS 10.12-era compatibility have not been verified on actual target machines. CI exercises installer safety on a modern macOS runner; it does not establish historical OS support.
